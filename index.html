Capabilities

Built for Enterprise AI Governance

Everything you need to expose internal tools to LLMs — safely, auditable, and at scale.

🏢

Multi-Tenant Isolation

Every query filters strictly by organization_id from JWT. Cross-tenant requests return 403/404.

🔐

JWT Auth & RBAC

OAuth2 password flow with bcrypt. Roles (owner, user) gate sensitive operations.

📌

Immutable Versioning

Skills can't be mutated. Updates create new versions that require explicit owner activation.

📜

Audit Trails

Every create, activate, execute, and disable action is logged with actor and version ID.

✅

JSON Schema Validation

Payloads are validated against each skill's schema. Invalid input returns 422 with explicit errors.

🤖

LLM Agent Orchestrator

Active skills auto-format into OpenAI/Gemini-compatible function definitions.

Get Running

Quick Start in 5 Minutes

Clone, install, seed, and run. No external services required.

# Clone and install
git clone https://github.com/rizbot4u/jarvis-skills-registry.git
cd jarvis-skills-registry
pip install -r requirements.txt

# Seed test users
python seed_users.py

# Start the API
uvicorn app.main:app --reload

# Open Swagger UI
# http://localhost:8000/docs
Reference

Core API Endpoints

Full OpenAPI 3.1 spec at /docs when running.

MethodEndpointDescription
POST/tokenAuthenticate and receive a JWT
GET/skillsList skills for your organization
POST/skillsCreate a new skill draft
POST/skills/{id}/versionsCreate a new immutable version
POST/skills/{id}/activateActivate a version (owner only)
POST/skills/{id}/executeExecute a skill with schema validation
GET/skills/activeList only active skills
DELETE/skills/{id}Disable a skill
POST/agent/runRun the LLM Agent Orchestrator
Agent Orchestrator

Turn User Prompts into Tool Calls

The orchestrator discovers your active skills, formats them for any LLM, and executes the chosen tool.

// Request
POST /agent/run
{
  "prompt": "Approve invoice #12345",
  "payload": {
    "skill_id": 1,
    "arguments": { "invoice_id": 12345, "amount": 250.0 }
  }
}

// Response
{
  "prompt": "Approve invoice #12345",
  "selected_skill_id": 1,
  "execution_response": {
    "skill": "Invoice Approver",
    "status": "executed",
    "organization_id": 1,
    "version": 1
  }
}
